# RiskSmart brand guidelines

Foundations for designing on-brand for the RiskSmart GRC platform: **Teal & Navy**, one
typeface (**Sora**), **WCAG 2.1 AA** baseline. Design language: clear, trustworthy, consistent —
built for regulated financial services.

These guidelines sit alongside the component library. The themed-cloudscape **components already
implement** the tokens, spacing, radius and elevation below — so you compose components, you don't
hand-roll their styling. Use these docs for **brand intent**: colour meaning, typography, voice &
copy, iconography, imagery, logo usage, and accessibility.

Guidelines: colour · typography · voice-and-tone · copy · iconography · visual-content · logo · accessibility · styles.
