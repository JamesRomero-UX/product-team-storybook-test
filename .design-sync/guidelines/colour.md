# Colour

Teal signals **action and confidence**; Navy carries **structure and text**. Colour always means
something — never decoration. Status colours are reserved for meaning and are **always paired with
a label**, never colour alone.

## Usage
- **Teal** — primary actions/CTAs, active nav, key metrics. Every view features teal.
- **Navy** — text, sidebar, top nav, structural lines.
- **Neutrals** — page background, white surfaces, borders.
- **Status** — validation, feedback, ratings only.

## Status & ratings
Error `#D92B2B` · Warning `#F2A041` · Success `#4E971A` · Info `#1976D2` · Critical `#CE1B1B`.
Risk ratings run Minimal → Low → Moderate → High → Critical, plus Unrated / Within appetite — always with a label.

Colours flow primitive → semantic → component; components reference **semantic tokens** only
(canonical values are OKLCH in the theme). Full ramps ship in the DS stylesheet.
