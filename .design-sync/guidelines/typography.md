# Typography

**Sora, everywhere** (`font-family: 'Sora', system-ui, sans-serif`; weights 300–800). Hierarchy
comes from **size and weight — never colour alone**. **Sentence case throughout.** Left-align most
copy; centre only short passages (hero, empty states, dialogs); **never justify**.

## Weights
- **400 Regular** — body, table cells
- **600 Semibold** — labels, nav, headings
- **700 Bold** — buttons, titles
- **800 Extrabold** — display, wordmark

## Live-app scale (size / weight)
- **48 / 700** — stat-card values (teal)
- **30 / 700** — page title
- **20 / 700** — widget / card title
- **18 / 600** — modal title
- **15 / 700** — button label
- **14 / 600** — nav items, labels, table headers
- **14 / 400** — table cells, body (most used)
- **12 / 400** — badges, chips, captions
