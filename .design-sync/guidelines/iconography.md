# Iconography

The **Untitled UI** icon set (`@untitled-ui/icons-react`) — the same package the app imports.
1.5–2px strokes, rounded joins, 24px grid, **20px in the UI**.

## Navigation mapping
`grid-01` Home · `bezier-curve-02` Internal audits · `zap` Risks · `file-check-01` Policy ·
`check-verified-03` Compliance · `users-plus` Third party · `settings-04` Controls ·
`alert-triangle` Issues · `check-circle-broken` Actions · `activity` Indicators ·
`certificate-02` Assessments · `bar-chart-10` Reports · `notification-message` Requests ·
`settings-01` Settings.

Common actions: plus, pencil-01, trash-01, download-01, refresh-02, check, x, chevron-down,
dots-vertical, eye / eye-off, info-circle, link-external-01. The full set (~1,100) lives in the
Untitled UI library. (Cloudscape components also accept their own `iconName`; use Untitled UI for
app navigation and custom chrome.)
