# Control Tower - new account provisioning

- Root account - control tower - make the account - techadmin+<account_name>@risksmart.com for IAM Identity Center and Email
- Go to IAM Identity Center to add permission sets for that account
- Remove default VPCs
- Set up identity provider for RiskSmart-GitHub-Deploy-Role in new account, if it doesn't already exist
- GithubDeployRole added to account for actions (if necessary)
