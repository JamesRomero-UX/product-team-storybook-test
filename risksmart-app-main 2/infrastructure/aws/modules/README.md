# Modules

We have modules available at [risksmart-terraform-modules][1], please see the [docs][2] for [adding][3] and [updating][4] modules.

This allows modules to be individually published as versioned artifacts through GitHub [releases][5], and used across multiple repos within the RiskSmart GitHub org.

You are welcome to continue using local modules if needed.
