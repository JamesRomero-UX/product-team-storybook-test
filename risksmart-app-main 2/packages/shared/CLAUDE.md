# packages/shared

Shared utilities used across frontend and backend packages.

## Key Modules

- `ai/` - AI-related utilities
- `approvals/` - Approval workflow logic
- `date/` - Date formatting and manipulation
- `forms/` - Form utility functions
- `hierarchy/` - Object hierarchy traversal
- `organisation/` - Organization-level utilities
- `reporting/` - Report generation helpers
- `third-party/` - Third-party integration utilities
- `htmlSanitizer.ts` - XSS-safe HTML sanitization
- `typeGuards.ts` - TypeScript type guard functions
